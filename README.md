# WDTCrimson

I'm a security engineer and software developer based in Indonesia. Most of my work is around PKI, HSM integration, and backend systems, especially the parts where protocols, applications, and infrastructure meet.

I've worked on certificate enrollment and lifecycle tooling, hardware-backed signing, tokenization integrations, and migration utilities. I like getting down to the protocol level when an API or abstraction doesn't tell the whole story.

## What I work with

- **Security and cryptography:** PKI, X.509, CVC/EAC, HSMs, PKCS#11, mTLS, certificate automation.
- **Backend development:** Java, PHP/Laravel, Go, Rust, SQL, and REST APIs.
- **Applications:** JavaScript/TypeScript, React, Electron, and Tauri.
- **Systems and tooling:** Linux, Windows Server, Docker, scripting, deployment, and troubleshooting.

## Outside of work

I tend to build tools for things I already spend time on: rhythm games, music software, game data, and desktop automation. Recent personal projects include a VOCALOID project inspection and tuning toolkit, a desktop assistant with voice integration, and web apps and Discord bots.

Most of my professional code isn't public. The repositories here are independent projects, experiments, and tools I can share.
